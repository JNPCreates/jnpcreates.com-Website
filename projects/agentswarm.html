AgentSwarm

Multiple terminals. One workspace. A VS Code extension that makes setting up an agent workflow a little less repetitive.

The idea

Working with several command-line agents can mean opening terminals, arranging splits, and typing the same startup command repeatedly. AgentSwarm brings that setup into a dedicated VS Code sidebar: choose a layout and launch the terminals together.

Choose a grid. Get to work.

Pick a preset such as 1 × 2, 2 × 2, or 2 × 4, or adjust the rows and columns yourself. Each terminal opens in the editor grid so you can keep several sessions in view.

  • Launch plain shells or enable a shared startup command for each terminal.
  • Use the layout for coding agents, command-line tools, or regular shell sessions.
  • Close the terminals launched by AgentSwarm with one command.

Behind the build

The extension is written in TypeScript. A sidebar provides the controls, while VS Code's extension APIs create the terminals and arrange the editor groups.

AgentSwarm handles the terminal setup. You choose what each session works on and how to coordinate the work. Startup commands run only when you enable that option.

Explore the project

The source and build instructions are on GitHub. You can build and package the extension locally, then install it in VS Code.
